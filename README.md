# Game Store Hexlet

Полноценный интернет-магазин игр. Есть две версии:

- **GitHub Pages** — статический сайт в папке `docs/` (каталог, регистрация, корзина, покупки, админка)
- **Flask** — серверная версия с SQLite для локальной разработки

## Возможности

- 100+ популярных реальных игр в каталоге
- Регистрация, логин/логаут, профиль пользователя
- Баланс пользователя в рублях и пополнение баланса
- Корзина и покупка игр
- Страница игры с полной информацией и выбором издания
- Админ-панель для управления играми и пользователями
- Светлая/тёмная тема и переключение языка RU/EN

## GitHub Pages (онлайн-версия)

1. Загрузите репозиторий на GitHub.
2. Откройте **Settings → Pages**.
3. **Source:** Deploy from a branch → **main** → папка **`/docs`** → Save.
4. Через 1–2 минуты сайт откроется по адресу:  
   **https://dzh1224.github.io/game-store/**

### Вход для администратора

- Логин: `admin`
- Пароль: `admin123456`

### Важно про данные на GitHub Pages

Данные (пользователи, корзина, покупки, баланс) хранятся в **localStorage браузера**. У каждого посетителя свой отдельный «магазин». Если очистить кэш браузера — данные сбросятся.

Чтобы обновить каталог игр из локальной базы Flask:

```bash
python scripts/export_static_data.py
```

## Локальный запуск (Flask + SQLite)

```bash
pip install -r requirements.txt
python app.py
```

Сайт: http://127.0.0.1:5000

Администратор создаётся автоматически при первом запуске (`admin` / `admin123456`).
